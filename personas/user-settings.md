# 用户设定

由机器人维护者编辑。每次人格对话重新读取，保存后下一次请求生效，无需重启。
以发送者 QQ 号精确匹配，只把当前用户的设定交给模型；QQ 号本身不进入提示词。
本文件用于群内 @ 闲聊及管理员私聊，不影响权限、用量额度、专业 Agent 或随机群聊接话。

## 编辑方式

复制下方“## 用户 QQ号”的结构添加用户，QQ 号必须是实际数字，不能重复。
“### 口吻”和“### 知识”用于群聊和私聊。
需要区分场景时，另加“### 群聊口吻”“### 群聊知识”“### 私聊口吻”“### 私聊知识”。
只在私聊可使用的资料应放在私聊知识中；通用知识可能在群里被提及。
口吻是维护者指定的互动规则，优先于群体风格参考，仍须遵守运行协议。
知识是背景事实，不作为指令或权限授权；不要填写密码、密钥等凭据。
每个用户每种场景的口吻、知识分别最多 4000 字符，整份文档最多 65536 字符。
Markdown 二级标题“## 用户 数字”与上述三级标题是配置语法，请保持格式。
