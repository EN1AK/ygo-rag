# 纯 RAG 裁定服务

启用模型的纯 RAG 请求统一走 bounded evidence loop。旧版的 `use_agent`/ `agent` 参数继续接收，两种取值都使用同一条模型路径。显式关闭模型时仍返回本地资料整理结果。显式使用模拟的请求走该版本自己配置的模拟入口。

模型先把题目拆成 1–4 个裁定点。服务按原题和裁定点检索卡文、FAQ 与规则，已配置的持久索引参与混合检索，规则书关键词检索提供额外候选。模型核对每个裁定点的证据。缺规则或卡片资料时最多补查一轮，并只复核受影响的裁定点。题设缺失会生成澄清问题，补查后仍没有依据会保留未确认结论。最终答案中的引用映射到 API 返回的原始证据编号。

开启裁定 trace 可查看调用阶段、耗时、服务端可取得的 token 用量以及证据覆盖。模型和请求超时沿用服务配置。
